Presentación del Equipo

Somos un equipo comprometido con la promoción de los destinos turísticos más representativos de El Salvador. Este sitio web fue desarrollado como un proyecto colaborativo para dar a conocer lugares de interés turístico, información relevante y recursos visuales para los visitantes.

Tecnologías y Herramientas Utilizadas

Para la elaboración de este proyecto se utilizaron diversas herramientas tecnológicas y recursos digitales:

  • HTML5 para la estructura del sitio web.
  • CSS3 para el diseño, estilos y presentación visual.
  • Claude AI como apoyo para generación y organización de contenido.
  • GitHub para control de versiones y colaboración.
